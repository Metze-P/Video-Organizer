# Video Organizer READ ME

## Overview

This program is a Python-based automation tool that organizes mp4 video files into folders based on the "Title" property in the files metadata. Files without "Title" metadata will be placed in a "No Title" folder. This program is **Windows only**.

## How to Run

### 1. Install dependencies

```
pip install -r requirements.txt
```

### 2. Folder placement

Place the [Video Organizer] folder within the directory with all the unorganized mp4 files.

### 3. Run the program

Double-click `run.bat`
